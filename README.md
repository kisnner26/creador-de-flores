# Creador de Flores

un cuaderno de bocetos en el navegador: dibuja flores a mano alzada, juega a atraparlas y descarga tu creación.

una sola página (`index.html`), sin dependencias ni build: html, css y javascript puro con `canvas` y svg.

## qué tiene

- **inicio**: ilustraciones de línea al estilo de un boceto botánico y pétalos flotando
- **juego** — *recoge las flores*: atrapa las flores que caen antes de que se acaben los 30 segundos y bate tu mejor marca
- **creador de flores**: elige el tipo (rosa, margarita, loto, tulipán, silvestre, cerezo), ajusta pétalos, tamaño, apertura, curva y tallo, cambia color, escenario y efecto (boceto, negrita, puntos, relleno)
- **firma y descarga**: escribe un nombre para firmar la flor y guárdala como PNG
- botón **aleatorio** para descubrir combinaciones

## cómo usarlo

abre `index.html` en el navegador. nada más.

o sírvelo local:

```bash
python3 -m http.server 8000
```

## diseño

estética de boceto sobre papel: fondo crema con textura de grano, tinta oscura, tipografías *IM Fell English*, *Cormorant Garamond* y *Dancing Script*, trazos finos y botones de contorno que se rellenan al pasar el cursor.
